# 🛍️ Customer Segmentation using K-Means Clustering

## 📌 Overview
This project uses the K-Means Clustering algorithm to group mall customers based on their annual income and spending score. Customer segmentation helps businesses understand different customer behaviors and create targeted marketing strategies.

## ✨ Features
- Data preprocessing
- Feature standardization
- Elbow Method to determine the optimal number of clusters
- K-Means clustering
- Cluster visualization
- Centroid visualization

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📂 Dataset
The dataset contains:
- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)

## 🚀 How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas matplotlib scikit-learn
   ```
3. Place the dataset (`mall_customers.csv`) in the project folder.
4. Run the Python script.

## 📊 Output
- Elbow Method graph
- Customer clusters
- Cluster centroids
- Scatter plot showing segmented customers
